01 About

Software that works for everyone who uses it.

I was born in Dahisar and have spent 13+ years writing software in Mumbai — starting with PHP and MySQL product work and growing into leading full-stack TypeScript platforms.

At BarrierBreak, an accessibility technology company, I own the core rules engine that powers every product the company ships: web, IDE, browser, mobile and AI. I built the A11yInspect VS Code extension and CLI end-to-end, automated VPAT/ACR compliance reporting, and delivered enterprise SSO and Stripe billing in the central auth service.

Away from the keyboard I'm usually behind a camera or on a motorcycle — at a track day or on a long tour. Both teach the same thing my work does: look carefully, then commit to a clean line.

03 Selected work

What I've built, and what changed because of it.

  • Developer tooling · sole developer

    A11yInspect for VS Code & CLI

    An accessibility auditor that lives where developers write code. It checks 17+ file types and frameworks — JSX/TSX, Vue, Angular, Svelte, Astro, MDX, Liquid, Twig, ERB — with diagnostics, quick fixes, CodeLens and AI explain/fix.

    The hard part was React: components are bundled with esbuild and rendered with renderToStaticMarkup in worker threads, with a Babel AST fallback when rendering isn't possible.

  • Core platform

    The accessibility rules engine

    Primary owner of BarrierBreak's proprietary engine — 31 modules and 640+ rule codes covering ARIA, contrast, forms, tables, landmarks, focus, target size and shadow DOM. It runs inside every product and the company's MCP server. Also built its admin platform: a Fastify + PostgreSQL API with 64 routes and a React/TanStack UI.

    • TypeScript
    • Fastify
    • PostgreSQL
    • MCP

  • Compliance

    VPAT / ACR reports on autopilot

    Automated VPAT 2.5 / ACR generation in Excel, Word and PDF across WCAG 2.1, Section 508, EN 301 549, IS 17802 and GIGW 3.0 — with AI-written conformance remarks, token tracking and caching — replacing hand-built reports.

    • LLM pipelines
    • Node.js
    • VPAT 2.5

  • Browser extensions

    Four browsers, one codebase

    Unified the Chrome, Edge and Firefox MV3 extensions into a single codebase, led the Safari port, and replaced per-browser sign-in with one token-exchange flow. Earlier: the DevTools panel, PDF/XLSX reports, user-flow audits and ruleset sync.

    • MV3
    • Safari
    • React
    • Vite

  • Auth & billing

    Enterprise SSO and Stripe subscriptions

    Hardened SAML SSO — IdP metadata and certificate validation, audit logs — and built the Stripe lifecycle: per-product cancellation, seat metering, free-plan grants and AI-token add-ons. Closed an org-level access-control flaw along the way.

    • SAML
    • Stripe Billing
    • Security

  • Mobile & IDE

    Taking checks beyond the web

    Bootstrapped 9 Swift packages (auditors, a VPAT CLI, an XCUITest library, an Xcode extension), added 62 automated WCAG 2.2 / HIG workflows to an iOS framework, built an Android Studio plugin, and an 89-rule zero-dependency ESLint plugin.

    • Swift
    • Kotlin
    • ESLint AST
    • Figma
